# StudyHub Minimal — Class 10 CBSE

A responsive, minimal personal study planner built with plain HTML, CSS and JavaScript. No framework, build step, or external library is required.

## Files
- `index.html` — page structure and sections
- `style.css` — layout, typography, responsive styles, light/dark themes
- `app.js` — syllabus data, navigation, local saving, tasks, notes, quizzes, countdowns, progress, backup
- `README.md` — this guide

## Run locally
1. Extract the ZIP file.
2. Keep all three code files in the same folder.
3. Open `index.html` in a current browser such as Chrome, Edge or Firefox.

For local use, this can run without a server. To publish, upload the folder to a static host such as GitHub Pages, Netlify or Vercel.

## Included features
- Dashboard and subject progress
- Chapter completion checklist
- Search/filter chapters
- Study task planner with completion status and suggestions
- Chapter notes editor and revision template
- Starter practice quizzes with explanations and saved scores
- Manual test result logging
- Progress report and test history
- Editable Pre-Board and Board target dates
- Light/dark theme
- JSON backup export
- Responsive mobile navigation

## Important notes
- Data is saved in `localStorage` on the current browser/device. It does not sync across devices. Export a backup regularly.
- This version does not include user accounts, cloud database, AI API integration, or a complete official question bank.
- The chapter list is a starter tracker, not a guarantee that every listed chapter is examinable in CBSE 2026–27. Verify the final syllabus with the official CBSE curriculum and school.
- The Board date defaults to 15 February 2027 as requested. Update it when the official subject-wise timetable is confirmed.
